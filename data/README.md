# 道の駅データ(michi-no-eki.json)

近畿(福井・滋賀・京都・大阪・兵庫・奈良・和歌山)と関東甲信(茨城・栃木・群馬・埼玉・千葉・東京・神奈川・山梨・長野)の道の駅のうち、位置を確かめられた駅の一覧です。家族向けアプリ「グルメ地図」で、地図に灰色の丸として表示するために作りました。

## 作り方(加工の内容)

1. 国土交通省の一覧から、対象の都府県の駅を取り出した(367駅)。
2. OpenStreetMap で「道の駅」の名前を持つ場所と名前を突き合わせた。比べる時は、「道の駅」の文字・空白・区切り記号・かっこの違いだけを無視した。
3. 名前が一致し、その場所が一覧の市町村の境界(OpenStreetMap の行政界)の中にある駅だけを採用した。同じ名前が2km以上離れて複数ある駅は採用しなかった。
4. 自動で確かめられなかった駅は、このファイルに入れていない。人が OpenStreetMap の地図か駅の公式サイトで確かめた駅は、`note` に根拠を書いて追加する(Googleマップの座標は使わない)。

作成に使ったプログラム: `data-src/build_michi.py`(アプリとは別の作業フォルダにあります)

## 項目

| 項目 | 内容 |
|---|---|
| `id` | アプリ用の番号(都道府県と駅名から作る。一覧の並びが変わっても同じ番号) |
| `name` / `pref` / `city` | 駅名・都道府県・市町村(国土交通省の一覧より) |
| `lat` / `lng` | 緯度・経度(OpenStreetMap より) |
| `source` | 位置を取った OpenStreetMap の要素、または手で確かめた出どころ |
| `note` | 位置を確かめた根拠 |
| `needsVisualCheck` | `true` の駅は、OpenStreetMap で「道の駅」の名前が付かない場所(同じ町の同名の施設)で位置を決めた駅。人が地図か現地で目で見て確かめるまで、アプリでは「位置は未確認(目視待ち)」と出す |

## 注意

- 位置は施設のおおよその場所です。ナビゲーションなど、高い精度が必要な用途には使わないでください。
- 新しく登録された駅、名前が変わった駅は、反映されていないことがあります(国土交通省の登録は年に2回ほど)。
